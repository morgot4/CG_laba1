# Текстуры лабораторной №3

Все PNG созданы для этой работы детерминированным скриптом `tools/generate_textures.py`.
Они уже лежат в репозитории: Python нужен только для изменения или повторной генерации карт.
Приложение читает файлы с диска через стороннюю библиотеку `stb_image`.

| Материал | Albedo | Specular | Emissive |
| --- | --- | --- | --- |
| Ceramic tiles | бирюзовая / светлая плитка | светлая плитка блестит, бирюзовая и швы матовые | чёрный пиксель |
| Copper panels | медные панели и заклёпки | панели блестят, швы почти матовые | чёрный пиксель |
| Lava | тёмная порода и трещины | слабый блик породы и более яркий в трещинах | трещины из периодического шума Перлина |
| UV grid | координатный градиент и сетка | чёрный пиксель | чёрный пиксель |

Изображения имеют размер 512×256, кроме `black.png` (1×1).
Для albedo/emissive используется sRGB, для specular — линейный UNORM.
В приложении цвет освещения вычисляется в линейном пространстве.
Сэмплер: линейная фильтрация, повторение по U/V, один mip-уровень.

Повторная генерация из корня проекта:

```sh
python3 tools/generate_textures.py
```

Список файлов материалов задаётся в `source/materials.cpp`.
Можно заменить PNG своими картинками; после перезапуска они загрузятся без перекомпиляции.
